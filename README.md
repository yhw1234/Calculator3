# 文本计算器 (Text Calculator)

基于 **Python + PyQt6** 开发的增强版文本计算器，双击 `文本计算器.bat` 即可启动。

## 特性

- **四则运算**：加 `+`、减 `-`、乘 `*`、除 `/`、幂 `^`/`**`、取模 `%`、整除 `//`
- **隐式乘法**：`2(3+4)`、`3π`、`2sin(30)`、`(1+2)(3+4)`
- **后缀阶乘**：`5!`、`3!+2`（支持半整数阶乘）
- **百分号**：`50% = 0.5`（自动与取模 `10%3` 区分）
- **科学计数法**：`2e3`、`1.5E-5`
- **变量定义与使用**：输入 `x=5` 后可用 `2x+1`
- **单位换算**：`1km+500m`、`2kg+500g`、`10min+30s`、`5ft+12in`
- **丰富数学函数**：三角/反三角、双曲（`sh`/`ch`/`th`）、对数（`ln`/`lg`/`lb`/`log`）、
  `sqrt`/`cbrt`/`root`、`gcd`/`lcm`（多参数）、`min`/`max`/`avg`/`sum`、
  `comb`/`perm`、`round`/`floor`/`ceil`、`sign`/`abs`/`clamp`、`heaviside`/`sinc` 等 40+ 个
- **常量**：π、e、τ、φ、∞
- **角度模式切换**：度 / 弧度 / 百分度
- **函数快捷输入栏**：顶部多行按钮栏，点击即可插入函数、常量、运算符
- **设置持久化**：小数位、保存/复制结果、窗口前置、字体大小颜色、`*÷→×÷`
- **自动保存/加载**上次计算结果与窗口位置
- **记事本模式**：行首加 `:` 不报错

## 文件说明

| 文件 | 说明 |
|------|------|
| `文本计算器.bat` | 双击启动脚本（自动调用 pythonw，无控制台窗口） |
| `calculator.py` | PyQt6 图形界面主程序 |
| `calc_engine.py` | 核心计算引擎（基于 `ast` 安全求值，禁止 `eval`/`exec`） |

## 环境要求

- Windows
- Python 3.10+
- PyQt6（`pip install PyQt6`）

## 使用方法

1. 确保已安装 Python 3.10+ 并勾选 "Add to PATH"
2. 安装 PyQt6：`pip install PyQt6`
3. 双击 `文本计算器.bat`
